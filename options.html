Copy to Figma

These apply every time you copy with the toolbar icon or Cmd+Option+O (Ctrl+Alt+O).

Claude header

Off: on artifact pages, paste only the artifact without the Claude title bar.

Resolution

× px
The page is resized to this viewport for the capture, then restored right after it is copied. Chrome/Brave show a "debugging" bar while it runs.

Clause (Figma)

After a successful copy, the Clause server presses paste in Figma for you (macOS). Needs npm run live running and Clause Assist open in Figma. If Clause isn't running, nothing happens and the copy stays on your clipboard.
